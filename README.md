A full-stack food ordering web application built using the MERN stack (MongoDB, Express.js, React.js, Node.js), allowing users to browse restaurants, explore a variety of food categories, add items to cart, and place orders seamlessly.

## 🚀 Features
- User authentication (Sign In / Sign Up)
- Browse diverse food categories (Salad, Rolls, Pasta, Desserts, Noodles, etc.)
- Search functionality for quick food discovery
- Add to cart and manage orders
- Responsive and modern UI design
- View top dishes near you
- Mobile app support (if applicable)

## 🛠️ Tech Stack
- **Frontend:** React.js, CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Other Tools:** (mention Mongoose, JWT, Stripe/Razorpay if used, Multer for image upload, etc.)

## ⚙️ Installation

1. Clone the repository
```bash
git clone https://github.com/your-username/your-repo-name.git
```

2. Install dependencies for frontend and backend
```bash
cd frontend
npm install

cd ../backend
npm install
```

3. Set up environment variables (.env) for MongoDB URI, JWT secret, etc.

4. Run the application
```bash
# Backend
npm start

# Frontend
npm start
```
